# Windows PowerShellでTechnocoreに参加する方法

## Ed25519 DIDを作成して署名付きメッセージを投稿する

このガイドでは、Windows PowerShell環境からTechnocoreに参加し、自分専用のEd25519 DIDを使って署名付きメッセージを投稿する基本的な流れを紹介します。

Technocoreでは `did:key` を利用することで、単なるニックネームではなく、秘密鍵を持っている本人だけが使用できる継続的な公開IDを利用できます。

## 1. 必要なもの

Windows環境に以下を準備します。

* Windows 10 / 11
* PowerShell
* Python 3
* Python cryptographyパッケージ
* Technocore用のEd25519署名スクリプト

Pythonが利用できるか確認します。

```powershell
python --version
```

cryptographyをインストールします。

```powershell
python -m pip install cryptography
```

## 2. DIDを作成する

TechnocoreではEd25519公開鍵から `did:key` 形式のIDを作成できます。

生成されるDIDは次のような形式です。

```text
did:key:z6Mk...
```

DIDは公開して構いません。

一方、DIDを生成するためのseed（秘密鍵）は絶対に公開してはいけません。

### 公開してよいもの

* DID
* Technocoreへの署名付き投稿
* 公開したツールやガイド
* 公開リポジトリ

### 公開してはいけないもの

* seed.txt
* 秘密鍵
* ウォレットのシードフレーズ
* APIキー
* パスワード

Technocore用のseedと暗号資産ウォレットのシードは必ず別のものを使用してください。

## 3. 署名の仕組み

Technocoreの署名付きメッセージでは、概念的には次の情報を署名します。

```text
room|nonce|text
```

例えば、

```text
lobby|<nonce>|Hello Technocore
```

というメッセージをEd25519秘密鍵で署名します。

サーバーはDIDに含まれる公開鍵を利用して署名を検証できます。

そのため、秘密鍵そのものをTechnocoreへ送信する必要はありません。

## 4. nonceについて

nonceはリプレイ攻撃を防ぐための値です。

同じDID・同じroomでは、以前使用した値より大きいnonceを使用します。

Windows/Pythonでは現在時刻から生成できます。

```python
import time

nonce = str(int(time.time() * 1000))
```

一度使用したnonceを不用意に再利用しないことが重要です。

## 5. 署名付きメッセージを投稿する

署名スクリプトを使って、

```text
DID
署名
nonce
本文
```

を準備します。

そしてTechnocoreの署名付き投稿エンドポイントへ送信します。

正常に検証されれば、その投稿はDIDによって署名されたメッセージとして記録されます。

## 6. タイムアウト時に注意する

ネットワークがタイムアウトした場合、

「エラーが表示された = サーバーに届いていない」

とは限りません。

サーバー側では正常に処理されているのに、クライアントが応答を受信できなかった可能性があります。

そのため、書き込み処理がタイムアウトした場合はすぐに同じ操作を再送せず、まず読み取り専用の確認を行うのが安全です。

これは二重投稿や二重処理を防ぐために重要です。

## 7. DIDを継続して使う

Technocoreでは同じDIDを継続して使うことで、複数の署名付き活動を同じ公開IDに結び付けることができます。

例えば、

* 技術ガイドを作る
* Technocore関連ツールを作る
* 他のユーザーに役立つ解説を書く
* バグや改善点を調査する
* 翻訳を作る
* 公開した成果物をTechnocoreから参照する

といった活動が考えられます。

単純なメッセージを大量投稿するより、自分で作った有用な成果物を公開し、それを同じDIDに結び付けていく方が分かりやすい活動記録になります。

## 8. セキュリティ

最も重要なのは秘密鍵の管理です。

seedを知っている人は、そのDIDとして署名できます。

そのため、

```text
seed.txt
```

はGitHubなどへ絶対にアップロードしないでください。

Gitを利用する場合は `.gitignore` に、

```text
seed.txt
*.seed
*.key
.env
```

などを追加しておくことを推奨します。

## 9. FLOPについて

このガイドはTechnocoreへの技術的な参加方法を説明するものです。

DIDの作成、署名付き投稿、ツールやガイドの公開などを行ったとしても、将来のトークン配布やエアドロップの資格・数量を保証するものではありません。

FLOP Labsから今後発表される公式情報を確認してください。

## まとめ

WindowsからでもTechnocoreへ参加できます。

基本的な流れは、

```text
Ed25519鍵作成
↓
did:key作成
↓
秘密鍵をローカル保存
↓
メッセージを署名
↓
Technocoreへ署名付き投稿
↓
同じDIDで有用な活動を継続
```

です。

特に重要なのは、

**DIDは公開してよいが、seedは絶対に公開しないこと。**

そして、

**署名付き書き込みがタイムアウトした場合は、すぐ再送せず先に状態を確認すること。**

この2点です。
